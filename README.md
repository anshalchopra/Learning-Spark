# Learning Apache Spark 🚀

This repository documents my learning journey through the book **"Learning Spark, 2nd Edition"**. Below is a summary of the key chapters and topics I have explored so far.

### **Chapter 1: Introduction to Apache Spark**
- The genesis and evolution of Spark.
- Spark’s key features: speed, ease of use, modularity, and unified analytics.
- Overview of Spark's architecture and distributed execution.

### **Chapter 2: Downloading Apache Spark and Getting Started**
- Steps to download and set up Apache Spark.
- Introduction to Spark’s shell (Scala and PySpark).
- Spark application concepts, including jobs, stages, and tasks.
- Understanding Spark’s transformation, actions, and lazy evaluation model.

### **Chapter 3: Apache Spark’s Structured APIs**
- RDDs and DataFrames: Benefits and underlying architecture.
- Working with DataFrames, Dataset API, and Spark SQL.
- Introduction to Spark's Catalyst Optimizer and the difference between DataFrames and Datasets.

### **Chapter 4: Spark SQL and DataFrames: Introduction to Built-in Data Sources**
- Using Spark SQL for data querying.
- Creating and managing SQL databases and tables in Spark.
- Working with common data sources (Parquet, JSON, CSV, Avro, ORC).
- Caching SQL tables and reading data into DataFrames.
